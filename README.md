The game begins by pressing enter and captions will show up on the screen to map out the storyline of each level.
The controls in this game are using the arrow keys or AWSD to move the character around the map, the enter key to advance when prompted, and R to restart the game. The game involves a storyline of a person’s daily life tasks. The user must collect all of the stars before advancing to the exit door. There is a sensory bar that steadily increases throughout the game and if the sensory gets too high, the player moves slower and the screen starts to dim and shake. If the sensory bar maxes out the player “dies” and the game resets.


Based on playtesting we decided to change the game to add more stars and a point system to each level. We also added sound effects to the game. We also chose to add more sensory zones as the levels progress to make the game more difficult. Peer feedback also revealed that we should make the character move faster which we changed as well.
